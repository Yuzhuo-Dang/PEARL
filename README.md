# PEARL: A dual-layer graph learning for multimodal recommendation

## Introduction

This is the Pytorch implementation for our INFFUS paper:

> Dang Y, Chen W, Pan Z, et al. PEARL: A dual-layer graph learning for multimodal recommendation[J]. Information Fusion, 2025, 122: 103168.

## Environment Requirement

- Python 3.9
- Pytorch 2.5.1+cu124

## Dataset

The original dataset is the publicly available [Baby/Sports/Clothing](http://jmcauley.ucsd.edu/data/amazon/links.html) datasets from Amazon.
